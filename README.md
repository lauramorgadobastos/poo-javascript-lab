Este repositório contém uma aplicação web interativa desenvolvida para praticar e consolidar os conceitos fundamentais de **Programação Orientada a Objetos (POO)** com JavaScript.

##  Objetivos do Projeto
- Aplicar conceitos centrais de POO: **Herança**, **Polimorfismo**, **Encapsulamento** e **Abstração**.
- Separar a interface visual (HTML/CSS) da regra de negócio (Classes em JS).
- Navegar entre as soluções através de uma interface interativa.

##  Tecnologias
- **HTML5**
- **CSS3**
- **JavaScript ES6+** (Classes e ES Modules)

## Exercícios Implementados
1. **Calculadora Geométrica:** Uso de herança e polimorfismo para cálculo de áreas.
2. **Agenda Telefônica:** Gerenciamento das entidades `Agenda` e `Contato`.
3. **Controle de Livros:** Associação entre `Empréstimo`, `Livro` e `Pessoa`.
4. **Gestão de Funcionários:** Regras de bônus específicas para `Funcionário` e `Gerente`.
5. **Simulador de Futebol:** Gestão de escalação e simulação entre `Time` e `Jogador`.
6. **Sistema de Supermercado:** Controle de estoque e checkout (`Pedido`, `Produto`, `Item`).
7. **Árvore Genealógica:** Relações familiares recursivas na classe `Pessoa`.
8. **Gestão Acadêmica:** Métodos estatísticos para médias e aprovações na classe `Turma`.
