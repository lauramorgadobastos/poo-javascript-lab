Este repositório contém uma aplicação web interativa desenvolvida para praticar e consolidar os conceitos fundamentais de **Programação Orientada a Objetos (POO)** com JavaScript.

---

##  Objetivos do Projeto

* **Conceitos de POO:** Aplicação prática de Abstração, Encapsulamento, Herança e Polimorfismo.
* **Arquitetura Clean Code:** Separação rígida entre a regra de negócio (Classes JS) e a interface visual (HTML5 e CSS3).
* **Navegação Dinâmica:** Interface unificada para alternar entre as 8 soluções desenvolvidas.

---

##  Exercícios Implementados

| Nº | Exercício | Conceitos de POO Aplicados | Classes Principais |
|:---:|---|---|---|
| **01** | Calculadora Geométrica | Herança e Polimorfismo | `FiguraGeometrica`, `Quadrado`, `Circulo` |
| **02** | Agenda Telefónica | Encapsulamento e Composição | `Agenda`, `Contato` |
| **03** | Controlo de Livros | Associação de Classes | `Emprestimo`, `Livro`, `Pessoa` |
| **04** | Gestão de Funcionários | Sobrescrita de Métodos e Herança | `Funcionario`, `Gerente` |
| **05** | Simulador de Futebol | Gestão de Coleções e Relações | `Time`, `Jogador` |
| **06** | Sistema de Supermercado | Fluxo de Caixa e Inventário | `Pedido`, `Produto`, `Item` |
| **07** | Árvore Genealógica | Relações Recursivas | `Pessoa` |
| **08** | Gestão Académica | Métodos Estatísticos e Manipulação de DOM | `Turma`, `Aluno` |
